# Matrix Rooms Search (MRS)

Go 1.26 Matrix public-rooms search service; `just` drives every build step and `vendor/` is authoritative.

## Commands

- Test: `just test` # coverage over ./...; writes cover.out (gitignored)
- Test one package: `just test ./internal/services`
- Single test: `go test -run <name> ./internal/services`
- Full check: `just lint && just test`
- Lint: `just lint`
- Build: `just build`
- Generate mocks: `just mocks` # reads .mockery.yml; rewrites internal/services/mocks_test.go
- Generate swagger: `just swagger` # after editing @Router or @Param annotations; `just lint` runs it first
- Prerequisites: go 1.26, just, golangci-lint v2, swag, mockery v3

## Layout

| Path | What lives there |
| --- | --- |
| `vendor/` | Vendored modules read by every build; kept in sync by `just update`. |
| `docs/docs.go`, `docs/swagger.json`, `docs/swagger.yaml` | Generated by `just swagger`; never edit by hand. |
| `internal/services/mocks_test.go` | Generated by `just mocks`; never edit by hand. |

## Conventions

- Register every endpoint in `controllers.ConfigureRouter` and annotate it with `@Router`: `TestSwaggerPathsMatchRouter` fails on a documented path the router does not register.

## Landmines

- Avatar responses stream only non-SVG images with nosniff; reuse isSafeImage for new media paths.
- `just lint` runs `comment-guard`, which reads `git ls-files` only: a new `.go` file is unchecked until it is staged.
- Builds read `vendor/`; adding or bumping a dependency needs `just update <module>@<version>` so go.mod, go.sum and vendor/ move together.

## Boundaries

- Ask first: `just update`.

## Pointers

- `docs/development.md` - four-step checklist for adding a search field. Read before touching the index mapping, result parsing, or query builder.
- `config.yml.sample` - every config key with its default. Read when adding a config option.
- `internal/repository/data/AGENTS.md` - bbolt bucket schema, server clocks, and room batch flushing. Read before changing storage methods.
- `internal/repository/search/AGENTS.md` - index mapping, analyzers, and Swap behavior. Read before changing index fields or multilingual analysis.
